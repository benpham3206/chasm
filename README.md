# chasm

Engineering journal for my from-scratch split Alice mechanical keyboard.

- Split Alice layout, inspired by the discontinued QK Alice Duo
- ZMK on nRF52840, Keygeek Y2 linears, PP plate
- Frosted CNC acrylic case, ball-catch opening, wireless with a wired USB-C hub + status display on the central half

See `roadmap-and-specs-v0.1.md` for the plan, `hardware/BOM.md` for the preliminary BOM (planning only, not order-ready), and `docs/references/` for build-process references.
