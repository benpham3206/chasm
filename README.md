# chasm

Engineering journal: from-scratch split Alice mechanical keyboard.

- Split Alice, inspired by QK Alice Duo
- ZMK, nRF52840, Keygeek Y2 linears, PP plate
- Frosted CNC acrylic case, ball-catch opening
- Wireless; wired USB-C hub + status display on central half
