# Decision: design rev 2 (user review of render v1)

*2026-10-04. User feedback on drafts 01_hero / 02_top + references in `ref/style/user-2026-10-04/`.*

| Topic | Decision |
|---|---|
| Case shape | Each half = a **"mini Evo75"** (Evoworks Evo75): its **silhouette** (box-on-wedge, graduated curve down the side) and **typing feel**, with the **clean lines of the Neo75**; side curve softer, ~Neo75 radius (refs `ref/shape/`, `ref/reviews/`). Review opinions are subjective - only feel + silhouette matter |
| Typing feel / mount | Evo75-style: **butterfly leaf-spring gasket mount**, PP plate, flex-cut PCB (supersedes generic gasket tabs; details from Evo75 media) |
| Consistency | Board shape and keycap detail must be consistent across both halves (v1 halves read as different shapes) |
| Macro column | M1–M4 column moves **down one key** (one row) |
| Knob | Moves to the **top-left corner of the left half** (was: right of Backspace on R). Hub still has no knob |
| Gull | **Remove the split gull accent** on the halves; add one **full gull logo on the right half, right of Up, above the Right arrow** (hub logo stays) |
| Keycaps | Redesign for max detail: **1:1 Cherry-profile PBTfans X-Ray recreation** (sculpt, dish, wall thickness, double-shot white legends, clear outer skin, homing bars, stem) |
| Keycap material | **White** X-Ray look (frosted clear skin over white double-shot body, like the kit photos), not clear/smoked |
| Mount | Gasket mount, Evo75-style leaf springs (see row above) |
| Shots | Photoreal set: default **warm oak desk, window light, hard shadows, full setup visible**; 1-2 **macro details** (points of interest); **exploded view in dark grey studio**. 01_hero was too far → closer. 03_plinth look liked (caps → white). Tent parked. 6b still showed the old hub knob → remove |
| Legends | **Exact X-Ray kit legends** (sublegends, icon mods, homing, font) |
| Edges | **Softer, rounded** (not Protagonist-crisp) |
| References | Protagonist X-Ray edition = very good reference; modmusings X-Ray collection media → `ref/modmusings-xray/` |
| Pipeline | Claude plans/orchestrates; **GPT-6.1 Sol via Codex CLI** = heavy tasks (Blender build); **GPT-6 Luna** = easy/web tasks. Devin paused |
